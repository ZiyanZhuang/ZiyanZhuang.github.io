# Font sources

Typography reference: https://www.collinslab.mit.edu/ (inspected 2026-10-17).
The reference uses Open Sans for body text, Abel for section headings, and
commercial Korolev Condensed for display headings/navigation. This homepage
uses Oswald as an openly licensed condensed alternative to Korolev; it does
not redistribute the reference site's commercial font files.

WOFF2 Latin subsets were obtained from the Google Fonts CSS API on 2026-10-17:
https://fonts.googleapis.com/css2?family=Abel&family=Open+Sans:ital,wght@0,300..700;1,300..700&family=Oswald:wght@400..600&display=swap

- Abel: regular 400; `abel-OFL.txt`
- Open Sans: variable 300–700, upright and italic; `opensans-OFL.txt`
- Oswald: variable 400–600; `oswald-OFL.txt`

License texts: https://github.com/google/fonts/tree/main/ofl
Font files are served locally with font-display: swap. Unsupported characters,
including Chinese and some scientific symbols, use the declared system fallbacks.
